# CS246-Watopoly

CS246-Watopoly is a console-based adaptation of the classic Monopoly board game developed as a team project for the University of Waterloo CS246 course.

The game supports turn-based multiplayer gameplay, property ownership, rent collection, player transactions, and event-based board mechanics. The project was designed using object-oriented programming principles and follows a modular architecture to support maintainability and future extensions.

## Technologies

- C++
- Object-Oriented Programming
- MVC Architecture
- Git
- Makefile

## Features

- Turn-based multiplayer gameplay
- Property purchasing and ownership
- Rent collection system
- Event and action squares
- Player movement across the board
- Save and load game functionality
